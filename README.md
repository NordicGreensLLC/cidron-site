# Cidron landing page
Plain HTML/CSS/JS, hosted free as a Render Static Site (publish path `.`).
To add an animation sample: drop a GIF in `samples/` and add a new card inside the `.grid` in `index.html` (3 per row on desktop), e.g.
`<figure class="slot filled"><img src="samples/name.gif" alt="..."><figcaption>Title</figcaption></figure>`.
